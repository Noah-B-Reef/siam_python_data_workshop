# UT SIAM Python Data Analysis Workshop

A hands-on introduction to data analysis, visualization, and modeling in Python. Using cereal nutrition data and the Iris flower dataset, the workshop covers data cleaning with pandas, exploratory plots, linear and polynomial regression, model evaluation and overfitting, linear programming, and classification with K-nearest neighbors and decision trees.

Open either notebook in Google Colab to get started:
